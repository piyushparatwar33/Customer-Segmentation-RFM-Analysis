# Customer Segmentation & RFM Analysis

## Project Overview
This project analyzes customer purchasing behavior using PostgreSQL and SQL.

## Objectives
- Analyze retail sales transactions.
- Calculate total revenue and orders.
- Identify top-performing products and customers.
- Analyze monthly and country-wise sales.
- Understand customer purchasing behavior.

## Tools & Technologies
- PostgreSQL
- SQL
- Python
- Pandas
- Power BI

## SQL Analysis
- Data exploration
- Revenue analysis
- Monthly sales trends
- Product performance
- Customer-level analysis

## Dataset
UCI Online Retail Dataset

https://archive.ics.uci.edu/dataset/352/online+retail

## Business Benefits
Helps businesses understand customer behavior, identify valuable customers, and improve customer retention strategies.
